# L'Atelier — téléchargements

Les fichiers d'installation de **L'Atelier** pour macOS et Windows.

- **Télécharger** : la dernière version est dans [Releases](../../releases/latest).
  - `ATELIER-macOS-AppleSilicon.dmg` — Mac à puce Apple (M1 et suivants)
  - `ATELIER-macOS-Intel.dmg` — Mac à processeur Intel
  - `ATELIER-Windows.zip` — Windows 10 et 11
- `version.json` et `abonnements.json` sont lus par l'application (dernière version publiée, liste signée des abonnements résiliés). Ils ne contiennent aucune donnée personnelle.
